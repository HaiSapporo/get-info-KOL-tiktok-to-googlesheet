# TikTok KOL Tracker — Google スプレッドシート + Apps Script + Apify

[English](README.md) | [Tiếng Việt](README.vi.md) | **日本語**

TikTok 動画のリンクを Google スプレッドシートに貼り付けて **GET** ボタンを押すだけで、動画ごとの **再生数・いいね数・コメント数・シェア数・保存数** を取得します。エンゲージメント率の計算と履歴の記録も自動で行います。

ソフトウェアのインストールは不要です。すべて Google スプレッドシート上で動作するため、ツールを導入できない社内 PC 環境でも利用できます。

## 主な機能

- **GET** ボタン 1 つで、A 列にあるすべてのリンクの数値を取得
- 通常の動画リンク、フォト投稿、短縮リンク（`vt.tiktok.com`、`vm.tiktok.com`、`tiktok.com/t/…`）に対応
- API を呼ぶ前にリンクをチェックするため、プロフィールリンクや TikTok 以外の文字列ではクレジットを消費しない
- 行ごとに分かりやすいエラーを表示（削除済み・非公開の動画、無効なリンク、API エラーなど）
- エンゲージメント率 =（いいね + コメント + シェア + 保存）÷ 再生数
- 取得に成功した数値は履歴シートにも追記されるため、伸びをグラフで追える
- Apify の API トークンは Script Properties に保存され、コードやシートには残らない

## 仕組み

```
Google スプレッドシート ──(Apps Script, UrlFetchApp)──► Apify API ──► TikTok
          ▲                                                │
          └──────────────── 動画ごとの数値 ◄───────────────┘
```

- **Apify を使う理由：** TikTok は Google のサーバーからの直接アクセスをブロックしています。Apps Script から TikTok のページを直接取得すると、データではなくボット対策のページが返ってきます（2026 年 10 月に確認）。
- **使用する Actor：** [`clockworks/tiktok-scraper`](https://apify.com/clockworks/tiktok-scraper)（入力は `postURLs`）
- **バッチ処理：** 1 回の Apify 実行につき最大 50 件のリンクを送ります。実行の完了を待ってから、結果を該当する行に書き込みます。
- **時間制限：** Apps Script は 1 回の実行が 6 分までのため、5 分を過ぎると新しいバッチは開始しません。残りは GET をもう一度押すと処理されます（更新が古い行から順に処理）。

## 必要なもの

- Apps Script の利用と外部サービス（`api.apify.com`）への接続が許可された Google アカウント
- [Apify](https://apify.com) のアカウント（Free プランで毎月 5 USD 分のクレジットあり）

## セットアップ

### 1. Apify トークンを取得する

1. [apify.com](https://apify.com) に登録します（Free プラン）。
2. Apify Console → **Settings → API & Integrations** を開き、**Personal API token** をコピーします。
3. 推奨：**Billing → Usage limits** で利用額の上限を設定します。

### 2. スクリプトを設置する

1. 新しい Google スプレッドシートを作成します。
2. **拡張機能 → Apps Script** を開き、既定のコードを削除して [`Code.gs`](Code.gs) の内容をすべて貼り付け、**保存** します。
3. スプレッドシートを再読み込みすると、**TikTok KOL** メニューが表示されます。
4. **TikTok KOL → 1. Tạo sheet & tiêu đề**（シートと見出しを作成）を実行します。初回は権限の確認が表示されるので **許可** します。
   `KOL_Tracking`（メイン表）と `Lich_Su`（履歴）の 2 つのシートが作成されます。
5. **TikTok KOL → 2. Nhập Apify API token**（Apify API トークンを入力）を選び、トークンを貼り付けます。
6. 動作確認（任意）：Apps Script エディタで `testFetch` を選択して **実行** します。実行ログにサンプル動画の数値が表示されれば成功です。

> 「このアプリは Google で確認されていません」と表示された場合は、**詳細 → （安全ではないページ）に移動** をクリックしてから **許可** してください。Google の審査を受けていない個人用スクリプトでは通常表示されるものです。

### 3. GET ボタンを追加する

1. `KOL_Tracking` シートで **挿入 → 図形描画** を開き、四角形を描いて **GET** と入力し、**保存して閉じる** をクリックします。
2. ボタンを見やすい位置に移動します。
3. ボタンをクリック → 右上の **⋮** → **スクリプトを割り当て** → `getStats` と入力して **OK**。
4. 推奨：**データ → シートと範囲を保護** で、利用者が編集できるのを A 列だけにします（他の列はスクリプトが書き込みます）。

## 使い方

1. **A 列** の 2 行目から、TikTok の動画リンクを 1 行に 1 つずつ（1〜20 件）貼り付けます。
2. **GET** を押して 1〜2 分待ちます。
3. B〜L 列に数値が表示されます。ステータス列（`Trạng thái`）が `OK` なら成功、`LỖI: …`（エラー）なら理由が表示されます。

その他のメニュー：

- **GET — lấy số liệu tất cả link**：ボタンと同じく、すべてのリンクを取得
- **Chỉ lấy các dòng đang chọn**：選択中の行だけを取得

注意：

- GET を押すたびに A 列の **すべて** のリンクを再取得し、リンク 1 件につき Apify の結果 1 件分のクレジットを消費します。新しいリンクを貼る前に、取得済みのリンクは削除してください（数値は履歴シートに残ります）。
- 図形描画のボタンは Google スプレッドシートのスマホアプリでは押せません。スマホではブラウザでシートを開き、**TikTok KOL** メニューを使ってください。

## シート構成

`KOL_Tracking` の列（見出しはベトナム語です）：

| 列 | 見出し | 内容 |
|----|--------|------|
| A | Link video | 動画 URL（入力） |
| B | KOL (username) | `@ユーザー名` |
| C | Video ID | TikTok の動画 ID |
| D | Ngày đăng | 投稿日 |
| E | Views | 再生数 |
| F | Likes | いいね数 |
| G | Comments | コメント数 |
| H | Shares | シェア数 |
| I | Saves | 保存数 |
| J | Engagement rate | （いいね + コメント + シェア + 保存）÷ 再生数 |
| K | Cập nhật lúc | 最終更新日時 |
| L | Trạng thái | ステータス：`OK` または `LỖI: …`（エラー） |

`Lich_Su`（履歴）には、取得に成功するたびに 1 行（日時、動画 ID、KOL、再生数、いいね、コメント、シェア、保存）が追記されます。ピボットテーブルやグラフで伸びを確認できます。

## エラーメッセージ

| 状況 | 表示されるステータス |
|------|----------------------|
| プロフィールリンク（`tiktok.com/@user`） | `LỖI: Đây là link trang cá nhân…`（プロフィールのリンクです。動画のリンクを貼ってください）。クレジット消費なし |
| TikTok 以外のリンク | `LỖI: Không phải link TikTok`。クレジット消費なし |
| 削除済み・非公開の動画 | `LỖI: NOT_FOUND — …` または他の Apify エラーコード |
| トークン未設定 | `LỖI: Chưa nhập Apify API token…` |
| トークンの誤り・クレジット不足 | `LỖI: Apify HTTP 401/402 …` |
| 実行時間の超過 | `LỖI: Apify chạy quá lâu…`：数分後にもう一度 GET を押してください |

エラーになった行は以前の数値が消去されるため、前のリンクの古いデータが残って表示されることはありません。

## 費用

- この Actor の料金は **結果 1,000 件あたり約 1.70 USD** です。最新の料金は Actor の Pricing タブで確認してください。
- Apify の Free プランには **毎月 5 USD 分のクレジット**（約 3,000 件分）が含まれます。
- 目安：リンク数 × GET を押す回数
  - 例：20 リンク × 1 日 5 回 × 30 日 = 3,000 件 ≈ 月 5 USD

## 他の人と共有する

**方法 A — 各自がコピーを使う（チーム外の人にはこちらを推奨）**

1. シートを **閲覧者** として共有します。
2. 相手は **ファイル → コピーを作成** を実行します。スクリプト、メニュー、ボタンもコピーされます。
3. 相手はメニュー 2 で自分の Apify トークンを入力します。コピーにあなたのトークンが残っている場合があるため、必ず置き換えてもらってください。

**方法 B — 1 つのシートを共有する（自分のチーム向け）**

- **編集者** として共有します。閲覧者・コメント可の権限ではスクリプトを実行できません。
- 全員があなたのトークンと Apify クレジットを使います。
- 編集者は Apps Script を開いて **プロジェクトの設定 → スクリプト プロパティ** からトークンを見ることができます。信頼できる人にだけ共有してください。トークンが漏れた場合は、Apify で新しいトークンを作成して入力し直してください。

## 制限事項

- **プロフィールリンクには非対応：** TikTok はプロフィールページをボット対策で保護しているため、クリエイターの動画一覧は取得できません。動画ごとのリンクを貼ってください。
- **数値の丸め：** TikTok アプリでは大きな数値が丸めて表示されます（例：19.6K）。シートには正確な値が表示されます。
- **データ提供元：** 結果は Apify の Actor に依存します。出力形式が変わった場合や提供元を変更する場合は、`Code.gs` の `fetchStatsBatch` と `mapResults_` を修正してください。
