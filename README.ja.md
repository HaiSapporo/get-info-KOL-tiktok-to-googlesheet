# Social Analysis — Google スプレッドシート + Apps Script + Apify

[English](README.md) | [Tiếng Việt](README.vi.md) | **日本語**

SNS 投稿のリンクを Google スプレッドシートに貼り付けて **GET** を押すだけで、投稿ごとのエンゲージメント数値を取得します。エンゲージメント率の計算と履歴の記録も自動で行います。

対応プラットフォーム：

| プラットフォーム | シート | 取得する数値 |
|------------------|--------|--------------|
| TikTok | `TikTok` | 再生数、いいね、コメント、シェア、保存 |
| Threads | `Threads` | 閲覧数、いいね、返信、再投稿、引用、シェア |

今後、他のプラットフォームも追加できます（[プラットフォームの追加](#プラットフォームの追加) を参照）。

ソフトウェアのインストールは不要です。すべて Google スプレッドシート上で動作するため、ツールを導入できない社内 PC 環境でも利用できます。

## 主な機能

- プラットフォームごとのシートに **GET** ボタン：そのシートの A 列にあるすべてのリンクを取得
- プラットフォームごとの履歴シート（`TikTok_LichSu`、`Threads_LichSu`）に、取得に成功するたびに記録
- **利用上限：** すべてのプラットフォーム合計で **1 日 500 件・1 か月 2,000 件** まで。Apify の費用超過を防ぎます
- API を呼ぶ前にリンクをチェック：プロフィールリンク、他サイトのリンク、重複はカウントされない
- 同じ投稿を 2 回貼った場合や、別の形式の URL（例：`threads.net` と `threads.com`）で貼った場合も、取得とカウントは 1 回だけ
- 行ごとに分かりやすいステータスを表示。エラーの行は以前の数値を消去
- Apify の API トークンは Script Properties に保存され、コードやシートには残らない

## 仕組み

```
Google スプレッドシート ──(Apps Script, UrlFetchApp)──► Apify API ──► TikTok / Threads
          ▲                                                │
          └──────────────── 投稿ごとの数値 ◄───────────────┘
```

- **Apify を使う理由：** SNS は Google のサーバーからの直接アクセスをブロックしています。Apps Script から TikTok のページを直接取得すると、データではなくボット対策のページが返ってきます（2026 年 10 月に確認）。
- **使用する Actor：**

  | プラットフォーム | Apify Actor | 料金（Free プラン） |
  |------------------|-------------|---------------------|
  | TikTok | [`clockworks/tiktok-scraper`](https://apify.com/clockworks/tiktok-scraper) | 1,000 件あたり約 1.70 USD |
  | Threads | [`lergassy/threads-scraper`](https://apify.com/lergassy/threads-scraper) | 1,000 件あたり約 2.00 USD |

- **バッチ処理：** 1 回の Apify 実行につき最大 50 件のリンクを送り、完了を待ってから結果を該当する行に書き込みます。
- **時間制限：** Apps Script は 1 回 6 分までのため、5 分を過ぎると新しいバッチは開始しません。残りは GET をもう一度押すと処理されます（更新が古い行から順に処理）。

## 必要なもの

- Apps Script の利用と外部サービス（`api.apify.com`）への接続が許可された Google アカウント
- [Apify](https://apify.com?fpr=f5khma) のアカウント（Free プランで毎月 5 USD 分のクレジットあり）

## Apify の使い方

[Apify](https://apify.com?fpr=f5khma) は、*Actor* と呼ばれる既製のスクレイパーをクラウドで実行できるプラットフォームです。このツールはプラットフォームごとに 1 つの Actor を Apify API 経由で呼び出します。スプレッドシートが投稿リンクを送り、Apify が自社のサーバーでデータを取得し、スクリプトがその結果を読み込みます。

> この README 内の apify.com への登録リンクは紹介リンク（`?fpr=f5khma`）です。

### アカウントを作成する

1. [apify.com](https://apify.com?fpr=f5khma) を開き、**Sign up** をクリックします。
2. Google、GitHub、またはメールアドレスで登録します。Free プランではクレジットカードは不要です。
3. 登録後は **Apify Console**（トークン、実行履歴、請求を管理する Web 画面）が開きます。

### API トークンを取得する

1. Apify Console で **Settings → API & Integrations** を開きます。
2. **Personal API token** をコピーします。
3. スプレッドシートで **Social Analysis → 2. Nhập Apify API token** を選び、貼り付けます。

トークンは他人に教えないでください。トークンを持っている人は誰でも Actor を実行し、あなたのクレジットを使えます。漏れた場合は同じ画面で新しいトークンを作成し、古いトークンを削除してから、シートに入力し直してください。

### ブラウザで Actor を試す（任意）

1. Actor ページ（[TikTok](https://apify.com/clockworks/tiktok-scraper) または [Threads](https://apify.com/lergassy/threads-scraper)）を開き、**Try for free** をクリックします。
2. 投稿 URL 欄（TikTok は `postURLs`、Threads は `postUrls`）に投稿リンクを 1 件追加します。
3. **Start** をクリックします。実行が終わると、スクリプトがシートに書き込む数値が **Output** タブに表示されます。

### 実行履歴と利用量を確認する

- **実行履歴：** GET を押すと、最大 50 リンクごとに 1 回 Actor が実行されます。各実行の状態、ログ、結果は Console → **Runs** で確認できます。行に Apify のエラーが表示されたときは、まずここを確認してください。
- **利用量：** Console → **Billing** で今月のクレジット使用量を確認できます。無料クレジットは毎月リセットされます。
- **利用額の上限：** **Billing → Usage limits** で上限を設定しておきましょう。シート側の 1 日・1 か月の件数上限と併せて機能します。

### 料金とプラン

- どちらの Actor も結果ごとの課金です。最新の料金は各 Actor の **Pricing** タブで確認してください。上位プランほど単価は下がります。
- **Free プラン** には毎月 5 USD 分のクレジットがあり、約 2,500〜3,000 件の取得に足ります。
- クレジットを使い切ると Apify は新しい実行を受け付けず、シートには `LỖI: Apify HTTP 402 …` と表示されます。翌月のリセットを待つか、[apify.com](https://apify.com?fpr=f5khma) でプランをアップグレードしてください。
- スクリプトは有料オプション（動画・画像のダウンロード、字幕、プロフィール行、返信）をオフにしているため、投稿そのものの分だけが課金されます。

## セットアップ

### 1. スクリプトを設置する

1. 新しい Google スプレッドシートを作成します（バージョン 1.x を使っていた場合はそのシートを開きます）。
2. **拡張機能 → Apps Script** を開き、既存のコードを削除して [`Code.gs`](Code.gs) の内容をすべて貼り付け、**保存** します。
3. スプレッドシートを再読み込みすると、**Social Analysis** メニューが表示されます。
4. **Social Analysis → 1. Tạo sheet & tiêu đề**（シートと見出しを作成）を実行します。初回は権限の確認が表示されるので **許可** します。
   `TikTok`、`TikTok_LichSu`、`Threads`、`Threads_LichSu` が作成されます。
5. **Social Analysis → 2. Nhập Apify API token**（Apify API トークンを入力）を選び、トークンを貼り付けます。
6. 動作確認（任意）：Apps Script エディタで `testTikTok` または `testThreads` を選択して **実行** します。実行ログにサンプル投稿の数値が表示されれば成功です。

> 「このアプリは Google で確認されていません」と表示された場合は、**詳細 → （安全ではないページ）に移動** をクリックしてから **許可** してください。Google の審査を受けていない個人用スクリプトでは通常表示されるものです。

### 2. 各シートに GET ボタンを追加する

1. `TikTok` シートで **挿入 → 図形描画** を開き、四角形を描いて **GET** と入力し、**保存して閉じる** をクリックします。
2. ボタンをクリック → **⋮** → **スクリプトを割り当て** → `getStats` と入力して **OK**。
3. `Threads` シートでも同じ操作をします。`getStats` は常に開いているシートを処理するので、どのボタンも同じ関数で動きます。
4. 推奨：**データ → シートと範囲を保護** で、利用者が編集できるのを A 列だけにします。

### バージョン 1.x（TikTok KOL Tracker）からのアップグレード

新しい `Code.gs` を貼り付け、**1. Tạo sheet & tiêu đề** を 1 回実行します。旧シート `KOL_Tracking` と `Lich_Su` は `TikTok` と `TikTok_LichSu` に名前が変わり、データ、列、既存の GET ボタンはそのまま使えます。保存済みのトークンも引き継がれます。

## 使い方

1. プラットフォームのシート（`TikTok` または `Threads`）を開きます。
2. **A 列** の 2 行目から、投稿リンクを 1 行に 1 つずつ貼り付けます。
3. **GET** を押して 1〜2 分待ちます。
4. 右側の列に数値が表示されます。ステータス列（`Trạng thái`）を確認してください。

**Social Analysis** メニュー：

| メニュー | 動作 |
|----------|------|
| GET — sheet đang mở | 開いているシートのリンクをすべて取得（ボタンと同じ） |
| GET — TikTok / GET — Threads | そのプラットフォームのシートのリンクをすべて取得 |
| Chỉ lấy các dòng đang chọn | 選択中の行だけを取得 |
| Xem hạn mức đã dùng | 今日・今月の使用件数を表示 |

注意：

- GET を押すたびにシート上の **すべて** のリンクを再取得します。新しいリンクを貼る前に、取得済みのリンクは削除してください（数値は履歴シートに残ります）。
- 図形描画のボタンはスマホアプリでは押せません。スマホではブラウザでシートを開き、メニューを使ってください。

## 利用上限

想定外の費用を防ぐため、スクリプトは Apify に送ったリンク数を、すべてのプラットフォーム合計でカウントします。

| 上限 | 初期値 | `Code.gs` の設定 |
|------|--------|------------------|
| 1 日 | 500 件 | `CONFIG.QUOTA_DAILY` |
| 1 か月 | 2,000 件 | `CONFIG.QUOTA_MONTHLY` |

- 日付・月はスクリプトのタイムゾーン（**Apps Script → プロジェクトの設定 → タイムゾーン**）に従います。
- 無効なリンクと重複はカウントされません。Apify が実行を開始できなかった場合（トークンの誤り、クレジット不足）は、その件数が戻されます。
- 上限に達すると、残りの行には `CHƯA CHẠY: hết hạn mức ngày …`（未実行：1 日の上限）または `… hạn mức tháng …`（1 か月の上限）と表示され、以前の数値はそのまま残ります。翌日・翌月にもう一度 GET を押してください。
- 同じシートを使う全員で同じカウンターを共有します。

## シート構成

各プラットフォームのシートの列（見出しはベトナム語です）：

| 列 | 見出し | 内容 |
|----|--------|------|
| A | Link bài đăng | 投稿 URL（入力） |
| B | Tài khoản | `@ユーザー名` |
| C | Post ID | 動画 ID（TikTok）または投稿コード（Threads） |
| D | Ngày đăng | 投稿日 |
| E… | *数値* | TikTok：Views, Likes, Comments, Shares, Saves<br>Threads：Views, Likes, Replies, Reposts, Quotes, Shares |
| … | Engagement rate | すべての反応の合計 ÷ 閲覧数 |
| … | Cập nhật lúc | 最終更新日時 |
| … | Trạng thái | ステータス：`OK`、`LỖI: …`（エラー）、`CHƯA CHẠY: …`（未実行） |

履歴シート（`<プラットフォーム>_LichSu`）には、取得に成功するたびに日時、投稿 ID、アカウント、すべての数値が 1 行追記されます。

投稿者が数値を非表示にしている場合（例：Threads のいいね数）、そのセルは 0 ではなく空欄になります。

## ステータス一覧

| 状況 | 表示されるステータス |
|------|----------------------|
| プロフィールリンク | `LỖI: Đây là link trang cá nhân…`（投稿のリンクを貼ってください）。カウントなし |
| 他サイトのリンク | `LỖI: Không phải link TikTok / Threads`。カウントなし |
| 削除済み・非公開の投稿 | `LỖI: NOT_FOUND — …` または他の Apify エラーコード |
| トークン未設定 | エラーダイアログ：`Chưa nhập Apify API token…` |
| トークンの誤り・クレジット不足 | `LỖI: Apify HTTP 401/402 …` |
| 1 日・1 か月の上限に到達 | `CHƯA CHẠY: hết hạn mức …` |
| 実行時間の超過 | `CHƯA CHẠY: hết thời gian…` または `LỖI: Apify chạy quá lâu…`：もう一度 GET を押してください |

## プラットフォームの追加

プラットフォーム固有の処理はすべて `Code.gs` の `PLATFORMS` オブジェクトにあります。Instagram や YouTube などを追加するには、次の項目を持つエントリを追加します。

| 項目 | 用途 |
|------|------|
| `name`、`sheet`、`historySheet` | 表示名とシート名 |
| `actor` | Apify の Actor ID（`owner~actor-name` の形式） |
| `metrics` | `{ key, label }` のリスト（数値の列） |
| `engagement(stats)` | エンゲージメント率の計算式 |
| `extractId(link)` | URL から投稿 ID を取り出す（結果の照合と重複除去に使用） |
| `validate(link)` | 無効なリンクならエラーメッセージ、有効なら `null` を返す |
| `buildInput(links)` | Actor に渡す入力 |
| `parseItem(item)` | Actor の結果 1 件を `{ keys, value }` に変換 |

その後、メニュー項目（例：`getInstagram`）を追加し、**1. Tạo sheet & tiêu đề** を実行して新しいシートに GET ボタンを追加します。利用上限は自動的に適用されます。

## 他の人と共有する

**方法 A — 各自がコピーを使う（チーム外の人にはこちらを推奨）**

1. シートを **閲覧者** として共有します。
2. 相手は **ファイル → コピーを作成** を実行します。スクリプト、メニュー、ボタンもコピーされます。
3. 相手はメニュー 2 で自分の Apify トークンを入力します。コピーにあなたのトークンが残っている場合があるため、必ず置き換えてもらってください。

**方法 B — 1 つのシートを共有する（自分のチーム向け）**

- **編集者** として共有します。閲覧者・コメント可の権限ではスクリプトを実行できません。
- 全員があなたのトークン、Apify クレジット、利用上限を共有します。
- 編集者は Apps Script を開いて **プロジェクトの設定 → スクリプト プロパティ** からトークンを見ることができます。信頼できる人にだけ共有してください。

## 制限事項

- **プロフィールリンクには非対応：** 投稿ごとのリンクを貼ってください。
- **数値の丸め：** アプリでは大きな数値が丸めて表示されます（例：19.6K）。シートには正確な値が表示されます。
- **非表示の数値：** 投稿者がいいね数や閲覧数を非表示にしている場合は空欄になり、エンゲージメント率が実際より低くなることがあります。
- **データ提供元：** 結果は第三者の Apify Actor に依存します。出力形式が変わった場合は、そのプラットフォームの `buildInput` / `parseItem` を修正してください。
